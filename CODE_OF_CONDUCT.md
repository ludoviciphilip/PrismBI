# Code of Conduct

PrismBI follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work.
Harassment or discrimination of any kind is not tolerated. Report problems privately to the
maintainer through a GitHub [security advisory](https://github.com/ludoviciphilip/PrismBI/security/advisories/new)
or by contacting [@ludoviciphilip](https://github.com/ludoviciphilip); reports are handled confidentially.
