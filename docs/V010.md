## Regras para todas as frentes
- `VisualCard.tsx` tem 2.000 linhas e é compartilhado. Coloque a lógica em módulos novos e deixe em `VisualCard.tsx` só a chamada (no máximo cerca de 30 linhas por frente), para o merge sair limpo.
- Migrações de projeto ficam num arquivo próprio da frente (`src/engine/migrations/<frente>.ts`) e são registradas com uma linha em `migrations.ts`. Projetos salvos antigos precisam continuar abrindo.
- Tipos compartilhados: acrescente **exatamente** as linhas abaixo em `src/types/bi.ts`. Cada frente adiciona só o seu bloco, e os blocos não se sobrepõem.
- Todo filtro ou ordenação de visual continua passando por `build_filter_context` e pelos comandos existentes. Nada de lógica de negócio nova escondida no React se ela puder viver no motor.
- Testes: vitest para tudo o que é novo, mais um teste de renderização que digita em cada campo de cada diálogo novo e confere a largura com `getBoundingClientRect` (ver skill tailwind-width-class-override). O Rust roda via `systemd-run` (comando no brief).
- Tela pequena: todo painel ou diálogo novo precisa caber em 1366×768.

```ts
export type CondFormatTarget = 'background' | 'fontColor' | 'dataBar' | 'icon';
export interface CondFormatStop { kind: 'lowest' | 'highest' | 'number' | 'percent'; value?: number; color: string; }
export interface ConditionalFormat {
  id: string;
  target: CondFormatTarget;
  /** Campo do visual que recebe a formatação (nome da coluna/medida como aparece em yAxisFields/xAxisField). */

  /** Valor que decide a cor; padrão = o próprio campo. */

  mode: 'rules' | 'gradient' | 'fieldValue';
  rules?: Array<ConditionalFormatRule & { valueKind?: 'number' | 'percent' }>;
  gradient?: { min: CondFormatStop; mid?: CondFormatStop; max: CondFormatStop };
  dataBar?: { positiveColor: string; negativeColor: string; showBarOnly?: boolean };
  icons?: { set: 'arrows' | 'traffic' | 'flags'; rules: ConditionalFormatRule[] };
}
// em VisualFormatConfig:
//   conditionalFormats?: ConditionalFormat[];   // o campo legado `conditionalFormatting` é migrado para cá
```
