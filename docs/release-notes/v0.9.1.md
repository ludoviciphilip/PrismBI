# PrismBI v0.9.1

## Windows x64 chegou 🎉

A partir desta versão o PrismBI roda nativamente no **Windows x64**, além do Linux (AppImage, `.deb`, `.rpm`), mantendo o mesmo motor Rust + DuckDB e a mesma interface.

### Como instalar

- **Instalador `.msi` (recomendado):** baixe `PrismBI_0.9.1_x64_en-US.msi` (ou `pt-BR`) na página de [Releases](https://github.com/ludoviciphilip/PrismBI/releases), rode o instalador e siga o assistente. O instalador já cuida do **WebView2** (necessário para a interface) em máquinas que ainda não o têm.
- **ZIP portátil:** baixe `PrismBI_0.9.1_x64-portable.zip`, descompacte em qualquer pasta e execute `prismbi.exe` — sem instalação, sem precisar de privilégios de administrador. Ideal para testar rápido ou rodar de um pendrive.

### Aviso do SmartScreen do Windows

Como o executável **ainda não possui certificado de assinatura de código** (code signing EV/OV), é esperado que o Windows mostre o aviso:

> **"O Windows protegeu o computador"**

Isso **não** significa que o instalador é malicioso — apenas que ele não tem uma assinatura digital reconhecida pela Microsoft (que custa uma assinatura anual paga). Para prosseguir:

1. Clique em **"Mais informações"**.
2. Clique em **"Executar assim mesmo"**.

Quem quiser conferir a integridade do pacote pode validar o hash SHA-256 contra o `SHA256SUMS.txt` publicado na release (assinado com Ed25519 pela mesma chave que o auto-updater do app já verifica).

### Como funcionam as atualizações no Windows

O auto-updater integrado (menu de Atualizações do PrismBI) já funciona no Windows, com o mesmo modelo de segurança do Linux:

- O app consulta o GitHub Releases, baixa o `SHA256SUMS.txt` e sua assinatura (`SHA256SUMS.txt.sig`), e só prossegue se a assinatura Ed25519 bater com a chave pública embutida no binário.
- **Instalação via `.msi`:** o PrismBI detecta que foi instalado em `Program Files` ou `%LOCALAPPDATA%\Programs`, baixa o novo `.msi`, confere o SHA-256 e roda `msiexec /i <instalador> /passive`; o app se fecha automaticamente para o instalador poder substituir os arquivos.
- **Versão portátil:** o PrismBI baixa o `.zip` da nova versão para a pasta **Downloads** e orienta você a descompactar e substituir o `prismbi.exe` manualmente (o mesmo comportamento do Linux "managed/unknown": o app nunca sobrescreve um binário que não instalou ele mesmo).
- Em nenhum caso o frontend informa URL ou hash ao backend — só o Rust decide, depois de verificar a assinatura.

### O Linux não muda

Esta release **não altera o comportamento no Linux**: os pacotes AppImage/`.deb`/`.rpm`, o hook de WebKitGTK do sistema, o Flatpak e o pacote AUR continuam exatamente como na v0.9.0.

### Lacunas conhecidas

- Assinatura de código (code signing) para Windows ainda não está configurada — ver aviso do SmartScreen acima.
- A instalação/upgrade via MSI, a renderização do WebView2, os diálogos nativos de arquivo e o prompt do Credential Manager do Windows no primeiro uso do chaveiro só podem ser validados por alguém com uma máquina Windows real.
