# VetroBI v0.11.0

## 🔤 PrismBI agora é VetroBI
- O projeto **PrismBI foi renomeado para VetroBI**. O identifier do app mudou de `dev.prismbi.app` para `dev.vetrobi.app`, e o repositório e as URLs do projeto passaram de `github.com/ludoviciphilip/PrismBI` para `github.com/ludoviciphilip/VetroBI`.
- **Seus dados e credenciais são migrados automaticamente na primeira abertura.** Na primeira vez que o VetroBI abrir, ele copia (sem apagar o original) os projetos salvos, preferências e sessões que estavam guardados sob o identifier antigo para a pasta nova — você não precisa abrir nem reconfigurar nada. No Linux isso cobre `~/.local/share`, `~/.config` e `~/.cache`; no Windows, `%APPDATA%` e `%LOCALAPPDATA%\EBWebView`. Credenciais salvas no chaveiro do sistema (senhas de conexão, chave de IA) também continuam acessíveis por um fallback que busca no serviço antigo quando não encontra no novo.
- **No Linux, o pacote `vetrobi` substitui o `prismbi`.** Instalar o `.deb` ou o `.rpm` do VetroBI remove automaticamente o PrismBI antigo (ou impede os dois instalados ao mesmo tempo), então não sobra ícone duplicado no menu de aplicativos.
- **Se você está na v0.10.0 ou numa versão anterior, baixe a v0.11 manualmente desta vez.** O atualizador automático das versões antigas só aceitava pacotes assinados vindos do repositório `PrismBI`; como o projeto mudou de repositório, essa é a única atualização que precisa ser feita manualmente. A partir da v0.11, as atualizações automáticas voltam a funcionar normalmente, já apontando para o repositório `VetroBI`.
- **AUR:** o pacote no Arch User Repository passa a se chamar **`vetrobi-bin`** (antes `prismbi-bin`).
